# Lord Walder Frey — Hermes Profile

Hermes Agent profile styled after **Lord Walder Frey** from **Westeros: The Adversaries**.

The oldest, most fertile, most patient, and most dangerous lord in the Riverlands — a man who turned a bridge into a dynasty, an army into an assassination, and a wedding into a massacre, all because he was laughed at when he asked to be respected.

Install: `hermes profile install ./<slug>` (see repo README).
