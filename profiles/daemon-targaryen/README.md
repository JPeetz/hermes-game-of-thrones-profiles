# Daemon Targaryen — Hermes Profile

Hermes Agent profile styled after **Daemon Targaryen** from **Westeros: House of the Dragon**.

A second son of House Targaryen who grew into the most dangerous man in Westeros — brilliant, mercurial, and animated by a wound he cannot name: the sense that the crown he was born to touch was never meant for him to hold.

Install: `hermes profile install ./<slug>` (see repo README).
