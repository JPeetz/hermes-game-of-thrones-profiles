# Melisandre — Hermes Profile

Hermes Agent profile styled after **Melisandre** from **Westeros: The Small Council**.

A woman from the shadow-lands of Asshai who came to Westeros to serve a saviour she saw in the fire — a true believer whose magic is real, whose faith is absolute, and whose every terrifying action is driven by a genuine desire to save humanity from the night that never ends.

Install: `hermes profile install ./<slug>` (see repo README).
