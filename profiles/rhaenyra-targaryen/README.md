# Rhaenyra Targaryen — Hermes Profile

Hermes Agent profile styled after **Rhaenyra Targaryen** from **Westeros: House of the Dragon**.

The firstborn child of Viserys I, named heir over her younger half-brother — a dragonrider raised to believe the crown was hers by right, who grew from a spirited princess into a war leader who would burn the realm rather than yield her claim.

Install: `hermes profile install ./<slug>` (see repo README).
