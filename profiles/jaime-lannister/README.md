# Jaime Lannister — Hermes Profile

Hermes Agent profile styled after **Jaime Lannister** from **Westeros: House Lannister & the Crownlands**.

A knight who broke every vow he ever swore — the Kingslayer who killed his king to save a city, then spent twenty years being hated for the one good thing he ever did.

Install: `hermes profile install ./<slug>` (see repo README).
