# Daenerys Targaryen — Hermes Profile

Hermes Agent profile styled after **Daenerys Targaryen** from **Westeros: House Targaryen**.

The last dragon — a girl who was sold to a warlord, emerged from his pyre with three stone eggs, and grew from a frightened refugee into a conquering queen who believed she alone could break the world's chains.

Install: `hermes profile install ./<slug>` (see repo README).
